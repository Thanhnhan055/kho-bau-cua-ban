# Kho Báu Của Bản – Bản sắc của mình

Website quảng bá mô hình giáo dục trải nghiệm văn hóa bản địa **Kho Báu Của Bản**.
Trang tĩnh: HTML + CSS + JavaScript thuần, không cần build.

## Chạy trên máy

Mở trực tiếp `index.html` bằng trình duyệt, hoặc chạy một server tĩnh:

```bash
npx serve .
```

## Cấu trúc

```
index.html            Trang chính
assets/css/style.css  Giao diện
assets/js/main.js     Menu, hiệu ứng cuộn, parallax, tabs, phóng to ảnh, form liên hệ
assets/images/        Hình ảnh từ booklet "Trải nghiệm văn hóa"
```
